
# McDonald's China MCP OAuth Adapter

A private OAuth adapter for connecting ChatGPT to the official McDonald's China MCP server.

## Status

This project is under setup. Do not deploy until the OAuth server and MCP forwarding implementation have been completed and tested.

## Security

- Never commit real MCP tokens or passwords.
- Store secrets only in Render environment variables.
- Keep order creation disabled until read-only tools have been tested.
